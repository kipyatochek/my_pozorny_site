# Персональный сайт

Небольшой адаптивный веб-сайт, разработанный в рамках изучения основ веб-программирования.

## О проекте

<img width="1897" height="980" alt="mnx5MnJLsFsteniMPQuk2AcjhVKLrJzyJbeZDb44jo9p2t_EzBJpjkvy80nKlv9kUMGeIQ_XhoNNqJc3Ftoy1QDd" src="https://github.com/user-attachments/assets/913bfb39-83b8-4fbc-a93a-1945f716ea91" />

Сайт представляет собой персональную страницу с информацией об интересах и увлечениях.

Реализованы три тематических раздела:
- **Музыка** — любимые исполнители.
- **Аниме** — подборка любимых произведений.
- **Друзья** — раздел с фотографиями.

## Используемые технологии

<img width="849" height="966" alt="eO5FXL0IW4TVtoQ0UYV4Qi4Z7l-jlPxF8b6Nu5KHMgsIMo4o12IoHhGHL9T7S-LNasUAtjCqIJuQZwcp2gq2Ca7K" src="https://github.com/user-attachments/assets/9edd5dc0-b77e-4147-84ab-c26241e375e8" />

- **HTML** — структура и содержимое страниц.
- **CSS** — оформление, Flexbox и адаптивная вёрстка.
- **Media Queries** — адаптация интерфейса под мобильные устройства.

## Особенности реализации

- Одностраничная структура сайта.
- Навигация по разделам с помощью якорных ссылок.
- Плавная прокрутка страницы.
- Карточки с изображениями и описаниями.
- Адаптация расположения элементов под ширину экрана.
